# 医学条件生成与 FD 损失适配项目档案

## 任务与已完成范围

导师希望把 Representation Fréchet Loss for Visual Generation 的分布损失思路用于医学图像生成，并以 PIXEL 的数据或框架作为参考。PIXEL 包括基于 Stable Diffusion/ControlNet 生成解剖对齐的健康与患病图像，再做病灶定位的流程。现有材料支持的是 CheXpert 条件 GAN 上的方法适配与实验，不能把这些结果改写成已经完成 PIXEL 扩散训练。

项目组织可说“将评价距离转为生成训练目标，并研究估计稳定性和条件一致性”。FD-loss 的原方法来自原论文，个人工作是医学数据与条件任务适配、实验比较和问题分析。不能将损失原理宣称为个人首创。

## 生成器如何接受训练信号

二分类代码中，噪声 `[B,128]` 与类别嵌入 `[B,128]` 拼接，经全连接得到 4×4 特征，再逐级上采样为 `[B,1,128,128]`。投影判别器将图像特征与标签嵌入做内积，使真实性评价依赖条件。G 使用 `-D(G(z,y),y)`，D 使用 hinge loss。

FD 路径是：噪声与条件 → G → 生成胸片 → 冻结医学编码器 → 特征均值与协方差 → FD → 反向传回 G。冻结编码器参数不等于把这条路径放进 no_grad；生成特征若整体 detach，生成器就学不到 FD 约束。

FD 的形式为：

`||mu_g-mu_r||² + tr(Sigma_g+Sigma_r-2*(Sigma_r^(1/2)*Sigma_g*Sigma_r^(1/2))^(1/2))`。

第一项比较特征中心，第二项比较特征的变化结构。常用 FID 采用 Inception 特征；CXR-FD 换成医学编码器。特征空间不同，数值尺度和含义不同，不能直接比大小。FD 不保证医学正确，也不是对真实患者的诊断准确率。

## 小 batch 与历史统计

直接用很小 batch 估协方差会噪声大，甚至秩不足。FeatureQueue 保存 detached 历史特征；计算当前 loss 时，用当前可微特征替换将被淘汰的一段，更新 sum 与 outer-product，再算均值和协方差。反传结束后才正式 enqueue。历史队列扩大统计支持，却不会让历史样本重新经过生成器反传。

EMA 用衰减统计平滑变化，但存在初始化偏差、滞后与动量选择。它不是生成器参数 EMA，也不等于 Queue。当前源包没有 EMA 实现，解释时根据报告讲设计与结果，不指着二分类 Queue 代码说它就是最终 EMA。

报告中的 class-zscore 处理按组特征尺度，动态组权重处理梯度失衡，约 5% 指 FD 对生成图像的辅助梯度比例约束；它不是“FD loss 数值占总 loss 的 5%”。当前早期脚本只有固定 lambda 与 warmup，不能冒充完整最终 GB-CFD 实现。

## Core5 同预算主结果

| 指标 | Base28 | EMA99 | Queue2048 |
|---|---:|---:|---:|
| 宏平均 FID ↓ | 59.4950 | 61.8403 | 57.4315 |
| 宏平均 KID ↓ | 0.067280 | 0.072191 | 0.062641 |
| 宏平均 CXR-FD ↓ | 24.6504 | 15.7581 | 14.6423 |
| 宏平均 z-CXR-FD ↓ | 107.4145 | 65.9981 | 60.3433 |
| Exact Match ↑ | 8.29% | 11.29% | 11.40% |
| Hamming Accuracy ↑ | 64.69% | 65.94% | 66.55% |

来源是原最终实验报告第 15.5 节；同父模型、同续训预算、相同测试条件和噪声，医学评价用独立 DenseNet-121。这里是六个参考组的宏平均分布指标，不能省略聚合方式而暗示单次全局 FID。Queue 的宏平均 FID 相对下降约 3.47%，CXR-FD 下降约 40.60%；Exact Match 增加 3.11 个百分点。Atelectasis 条件 F1 仍下降，严格匹配率绝对值也较低。

FD-SIM 的 50k 协议、追加训练与特征空间不同，不能与上述同预算表拼成一条提升曲线。后训练分布改善，也不保证全部病种 F1 改善。

## 30 秒介绍

我在 CheXpert 条件生成任务中，把表征空间 FD 从评价指标引入生成训练，并比较历史队列、EMA 和梯度稳定化策略。Core5 历史实验按患者划分、统一父模型与续训预算，用独立评价器比较生成分布和条件一致性。Queue2048 的宏平均 FID 与医学特征距离都有改善，但病种控制仍有限制。

## 2 分钟介绍

原任务是将 FD-loss 思路迁移到医学图像生成。我完成的实验主线是条件 GAN，而不是完整复现 PIXEL。难点在于 FD 依赖特征分布统计，小 batch 协方差不稳定，而且特征尺度和各组梯度差异会影响训练。我比较 Queue 与 EMA，并在最终实验中使用按组标准化、动态权重和辅助图像梯度比例控制。Core5 允许五病种共现，并加入设备和视角条件；训练与测试按患者互斥划分。主对照从相同 Common20 模型出发、各续训 8 个 epoch，由独立 DenseNet 评价。Queue2048 把宏平均 FID 从 59.4950 降到 57.4315，CXR-FD 从 24.6504 降到 14.6423。部分病种 F1 下降，所以结论是生成分布与部分条件表现改善，不是临床有效性已经得到证明。当前公开源码覆盖较早二分类路径，最终实验结果保留为历史报告证据。

## 5 分钟讲述顺序

任务及完成范围 40 秒；条件 GAN 与 FD 梯度路径 70 秒；小 batch、Queue/EMA 和梯度稳定 70 秒；Core5 数据与公平评估 60 秒；收益、反例和源码缺口 60 秒。用手画图解释冻结网络可回传梯度，比逐字背公式更重要。
